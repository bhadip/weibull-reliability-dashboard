# Weibull Reliability Dashboard — Phase 1

This project is a **Phase 1** implementation of a Weibull Reliability Dashboard built with **Streamlit** and **Plotly**.

## Overview

- **Data source**: Google Sheets (connected via `st-gsheets-connection` with a service account)
- **Visualization**: Interactive Plotly charts for Weibull distribution analysis
- **Framework**: Streamlit for the web-based dashboard UI

## Purpose

Provide an interactive reliability engineering dashboard that reads failure/time-to-event data from Google Sheets and performs Weibull analysis, enabling teams to visualize reliability metrics without manual data processing.
